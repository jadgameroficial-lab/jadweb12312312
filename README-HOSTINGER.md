# JAD WEB | versão para Hostinger

Site institucional premium desenvolvido com Next.js, React, TypeScript e
Tailwind CSS.

## Publicação na Hostinger

No hPanel, use **Node.js Web App** e importe este projeto pelo GitHub ou envie
o ZIP.

Configuração recomendada:

- Framework: `Next.js`
- Versão do Node.js: `22.x` (20.x ou 24.x também são compatíveis)
- Comando de instalação: `npm ci`
- Comando de build: `npm run build`
- Comando de inicialização: `npm start`
- Diretório raiz: raiz do repositório

O projeto não exige banco de dados ou variáveis de ambiente para exibir o site.

## Desenvolvimento local

```bash
npm install
npm run dev
```
